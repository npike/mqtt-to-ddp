# MQTT to DDP Bridge

This script acts as a bridge between MQTT and DDP, allowing you to control a DDP-enabled device as an RGB light in Home Assistant.

## Features

*   Connects to an MQTT broker.
*   Registers itself as an RGB light with brightness control in Home Assistant using MQTT discovery.
*   Translates MQTT commands to DDP packets.
*   Sends DDP packets to a specified IP address and port.
*   Configuration via an external `config.ini` file.

## Installation

1.  **Clone the repository or download the files.**

2.  **Create and activate a Python virtual environment:**

    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

    _Note: On Windows, the activation command is `venv\Scripts\activate`_

3.  **Install the required Python libraries:**

    ```bash
    pip install -r requirements.txt
    ```

## Configuration

1.  **Rename `config.ini.example` to `config.ini`** (or create a new `config.ini` file).

2.  **Edit `config.ini` with your settings.**

    The `config.ini` file is structured to support multiple DDP lights. Each light is defined in its own section, starting with `light_`.

    *   **[mqtt]**
        *   `broker`: The IP address or hostname of your MQTT broker.
        *   `port`: The port of your MQTT broker (usually 1883).
        *   `user`: The username for your MQTT broker (if any).
        *   `password`: The password for your MQTT broker (if any).
        *   `base_topic`: The base topic for Home Assistant discovery (usually `homeassistant`).

    *   **[light_your_light_id]** (e.g., `[light_living_room]`, `[light_kitchen_counter]`).
        *   The section name itself (after `light_`) will be used as the `unique_id` for Home Assistant.
        *   The `name` displayed in Home Assistant will be automatically generated by replacing underscores with spaces and converting to title case (e.g., `light_living_room` becomes `Living Room`).
        *   `device_ip`: The IP address of your DDP device.
        *   `device_port`: The port of your DDP device (usually 4048).
        *   `pixel_count`: The number of RGB pixels in this light strip.

    **Example `config.ini`:**

    ```ini
    [mqtt]
    broker = 127.0.0.1
    port = 1883
    user = your_mqtt_username
    password = your_mqtt_password
    base_topic = homeassistant

    [light_living_room]
    device_ip = 192.168.1.101
    device_port = 4048
    pixel_count = 100

    [light_kitchen_counter]
    device_ip = 192.168.1.102
    device_port = 4048
    pixel_count = 50
    ```

## Usage

Run the script from your terminal:

```bash
python mqtt_to_ddp.py
```

The script will connect to the MQTT broker, publish discovery topics for all configured lights, and wait for commands. You should see your configured lights appear in your Home Assistant interface.

## Running as a Linux Service (systemd)

To run the `mqtt-to-ddp` script automatically when your Linux server boots (e.g., Ubuntu 22.04 LTS), you can set it up as a systemd service.

1.  **Create the service file:**
    Create a file named `mqtt-to-ddp.service` in `/etc/systemd/system/` with the following content:

    ```ini
    [Unit]
    Description=MQTT to DDP Bridge Service
    After=network.target

    [Service]
    ExecStart=/path/to/your/project/venv/bin/python /path/to/your/project/mqtt_to_ddp.py
    WorkingDirectory=/path/to/your/project
    Restart=always
    User=your_username

    [Install]
    WantedBy=multi-user.target
    ```

2.  **Edit the service file:**
    You need to replace the placeholder values in the `mqtt-to-ddp.service` file:

    *   Replace `/path/to/your/project/` with the actual absolute path to your `mqtt-to-ddp` project directory (e.g., `/home/your_username/mqtt-to-ddp/`).
    *   Replace `your_username` with the Linux username you want the service to run as.

    **Example `ExecStart` line:**
    If your project is in `/home/npike/mqtt-to-ddp/` and your virtual environment is named `venv`:
    `ExecStart=/home/npike/mqtt-to-ddp/venv/bin/python /home/npike/mqtt-to-ddp/mqtt_to_ddp.py`

3.  **Reload systemd:**
    After modifying the service file, reload the systemd daemon:

    ```bash
    sudo systemctl daemon-reload
    ```

4.  **Enable the service:**
    Enable the service to start automatically on boot:

    ```bash
    sudo systemctl enable mqtt-to-ddp.service
    ```

5.  **Start the service:**
    Start the service immediately:

    ```bash
    sudo systemctl start mqtt-to-ddp.service
    ```

6.  **Check the service status (optional):**
    To verify that the service is running correctly:

    ```bash
    sudo systemctl status mqtt-to-ddp.service
    ```

    This will show you if the service is active, running, and any recent log messages.
